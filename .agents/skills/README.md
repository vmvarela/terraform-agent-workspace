# Skills

Procedimientos reutilizables y opcionales. Un skill es una guía paso a paso que se carga solo cuando la tarea encaja; no es un paso obligatorio de enrutado. Los skills sobre Terraform se aplican siempre a un repositorio objetivo clonado bajo `projects/<repo>`, con las reglas y verificaciones de ese repo.

- `terraform-change/` — secuencia plan → revisión → aprobación → apply.

Añade aquí otros procedures propios cuando estén probados y sean reutilizables. No instales skills automáticamente.
