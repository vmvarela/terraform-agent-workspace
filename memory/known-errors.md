# Known errors — libro de registro

Errores conocidos de este entorno/proveedor y su solución probada. Vacío de partida: solo la plantilla. Antes de añadir, busca si ya existe una entrada para el mismo error y actualízala en lugar de duplicar.

## Plantilla

```markdown
## <Mensaje de error (resumido)>

- **Fecha**: AAAA-MM-DD
- **Ámbito**: herramienta / proveedor / versión
- **Síntoma**: mensaje de error exacto (redactado, sin credenciales).
- **Solución probada**: pasos que funcionaron.
- **Falso positivo a evitar**: lo que NO funciona o parece obvio y no lo es.
- **Evidencia**: comando/salida que lo confirma (sin secretos).
```
