# DevOps lessons — libro de registro

Lecciones duraderas y verificadas aprendidas trabajando en este workspace. Vacío de partida: solo la plantilla. Añade entradas únicamente cuando algo se haya comprobado, no suposiciones.

## Código de estilo

Cada entrada es genérica, con fecha, ámbito y evidencia. No incluyas secretos ni identificadores internos.

## Plantilla

```markdown
## <Título de la lección>

- **Fecha**: AAAA-MM-DD
- **Ámbito**: proveedor / repo / entorno
- **Qué pasó**: descripción breve del problema o comportamiento.
- **Por qué (causa raíz)**: causa real, no la sintomática.
- **Lección / regla**: corrección o hábito adoptado.
- **Evidencia**: comando/salida/diff que lo demuestra (sin secretos).
- **Fuente**: quién lo verificó (usuario, agente, etc.).
```
